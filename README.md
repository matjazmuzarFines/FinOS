# FIN:OS

Fines Operating System - notranje vodenje podjetja FINES d.o.o. (Administracija, Moj Fines, FIN:DOOR).

- Navodila projekta: `AGENTS.md`, slog: `finos_stil.txt`, skupna pravila: `../FINES_Standardi/app_instructions.md`.
- Lokalno: `npm install`, `npm run dev` (ali `npm run build` + `npm start`).
- Vercel: Framework preset Next.js, spremenljivki `NEXT_PUBLIC_SUPABASE_URL` in `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
